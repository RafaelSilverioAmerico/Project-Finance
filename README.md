# Finance — Controle de Gastos Pessoais

Projeto de estudo para aprender Spring Boot e JavaScript na prática, construindo
uma aplicação real de controle financeiro pessoal.

## O que o projeto faz

- Registro de gastos do dia a dia, organizados por categoria
- Resumos automáticos: diário, semanal e mensal
- Dashboard que atualiza em tempo real (WebSocket) conforme os gastos são registrados
- Autenticação multi-usuário com JWT — cada pessoa vê só os próprios dados
- Hospedado em servidor próprio (self-hosted)

## Stack

- **Backend:** Java 17, Spring Boot, Spring Security (JWT), Spring Data JPA, WebSocket, MySQL
- **Frontend:** HTML, CSS e JavaScript puro (sem frameworks), Chart.js
- **Infra:** Docker, rodando em servidor pessoal
